# AI-Powered-Optics

A public site for sharing learnings and thoughts about AI and optical systems.

## About

This site explores the fascinating intersection of artificial intelligence and optics, covering topics such as:
- Computer Vision
- Image Processing
- Deep Learning for optical pattern recognition
- Computational Photography

## Viewing the Site

The site is available via GitHub Pages. Simply enable GitHub Pages in the repository settings and point it to the main branch to make it publicly accessible.

## Local Development

To view the site locally:

```bash
python3 -m http.server 8000
```

Then open your browser to `http://localhost:8000`
